🎯 Project Overview
The objective of this project is to perform end-to-end manual testing on the Automation Test Store e-commerce platform. This involves verifying functional requirements, user workflows (registration, product catalog, cart management, checkout, and order placement), UI/UX consistency, and boundary conditions to ensure a stable and bug-free user experience.

🌐 Application Under Test (AUT)
Application Name: Automation Test Store

URL: https://automationteststore.com/

Application Type: E-Commerce Web Application

🔍 Testing Scope
In-Scope:
User Management: Registration, Login, Logout, Profile Update, and Password Reset.

Product Catalog & Search: Navigation across categories, filtering, sorting, and product search functionality.

Shopping Cart & Wishlist: Adding/removing items, updating quantities, and managing wishlist items.

Checkout & Payment Workflow: Guest/Customer checkout, shipping address management, payment method selection, and order placement.

UI/UX & Responsive Testing: Visual alignment, link validation, and cross-browser checks.

Out-of-Scope:
Performance, Load, and Stress Testing.

Automated Test Scripts (Focus is strictly on Manual QA processes).

Security Penetration Testing.

📊 QA Artifacts & Deliverables
Test Plan

Defines the scope, testing approach, resources, schedule, entry/exit criteria, and risks associated with testing the platform.

Requirement Traceability Matrix (RTM)

Maps functional requirements to corresponding test cases to ensure 100% test coverage.

Test Scenarios & Test Cases

Contains structured test cases covering positive and negative scenarios, boundary value analysis (BVA), and equivalence partitioning.

Defect Tracker / Reports

Logs identified bugs categorized by severity and priority, complete with steps to reproduce, expected results, and screenshot attachments.

🐞 Bug Life Cycle Management
Defects discovered during execution were logged and tracked through the following lifecycle stages:

New ➡️ Assigned ➡️ Open ➡️ Fixed ➡️ Retested ➡️ Closed / Reopened
